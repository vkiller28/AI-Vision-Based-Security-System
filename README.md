# 🛡️ AI Vision-Based Security System

An AI-powered vision-based security system that uses **Computer Vision and Deep Learning** to monitor environments and detect potential security threats in real time.

This project combines multiple AI models to provide intelligent surveillance capabilities such as face detection, mask detection, person detection, and camera tampering alerts.

---

## 📌 Overview

The system is designed to enhance security monitoring using real-time video analysis. It can be deployed on local machines or edge devices like Raspberry Pi for smart surveillance applications.

This project demonstrates practical implementation of AI in security and monitoring systems.

---

## 🎯 Features

✔ **Face Detection**  
Detects human faces in real time using deep learning models.

✔ **Mask Detection**  
Identifies whether a person is wearing a face mask.

✔ **Person Detection**  
Detects human presence in the camera's field of view.

✔ **Camera Tampering Detection**  
Alerts when camera obstruction, blackout, or tampering is detected.

✔ **Real-time Processing**  
Optimized for live camera feeds.

## ⚙️ How It Works

1. Capture live video feed from camera  
2. Process frames using AI models  
3. Perform detection tasks:
   - Face detection  
   - Mask classification  
   - Person detection  
   - Tampering detection  
4. Generate alerts or visual indicators
