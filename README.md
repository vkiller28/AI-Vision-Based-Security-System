# AI Vision-Based Security System

## Overview
This project is an AI-powered vision-based security system that uses computer vision and deep learning to monitor and detect potential security threats in real-time. The system includes features like face detection, face mask detection, person detection, and camera tampering detection.

## Features
- **Face Detection**: Detect faces in real-time using deep learning models.
- **Mask Detection**: Detect whether people are wearing face masks or not.
- **Person Detection**: Detect people in the camera's field of view.
- **Tampering Detection**: Alert the user when camera tampering or blackout frames are detected.
